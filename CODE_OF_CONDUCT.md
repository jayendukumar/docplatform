# Code of Conduct

We want this project to be useful, welcoming, and safe for everyone.

Participants must communicate respectfully, assume good intent while addressing impact, and focus criticism on ideas and behavior rather than people. Harassment, discrimination, threats, unwanted sexual attention, doxxing, and deliberate disruption are not acceptable.

Project maintainers may clarify, moderate, or remove contributions that violate these standards. Report concerns privately to the project maintainers through the repository's configured security or contact channel; do not publish sensitive details in an issue.

This is a repository policy draft. The project does not yet define a dedicated enforcement team or contact address; that operational detail must be selected before a public launch.
